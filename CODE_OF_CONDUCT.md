# Community code of conduct

Participants should communicate respectfully, give constructive technical feedback, and welcome contributors with different backgrounds and experience. Critique code and ideas using evidence. Respect privacy, accessibility needs, and reasonable boundaries.

Harassment, threats, discrimination, sexualized conduct, deliberate disruption, and publication of another person's private information are unacceptable. Do not post organizational documents, private search results, credentials, or personal details while discussing a bug.

Maintainers may edit or remove harmful content, restrict participation, or remove access in proportion to the impact and repeated behavior. They should explain decisions privately when appropriate and consider appeals impartially. Maintainers are subject to the same expectations.

Report conduct concerns privately through the **Contact me** form on the [maintainer's website](https://me.tovli.co.il/), identifying this repository and the relevant incident. Do not post sensitive details in a public issue. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

This policy applies in repository discussions, issues, pull requests, and project community spaces. It is an original project policy and does not claim to reproduce an external code-of-conduct standard.
